# ChillWithHomies

Ứng dụng React Native + Expo SDK 57 nằm trong `mobile/`. Dùng Node 22.13+ (nhánh 22) hoặc Node 24.3+ (nhánh 24).

```powershell
cd mobile
npm.cmd run web
```

Nếu chưa cài dependencies, chạy `npm.cmd ci` trong `mobile/` trước.

Mở `http://localhost:8081/design-system` để xem Amber design system, hoặc chọn
**Explore Amber design system** trên màn hình đăng nhập.

Xem [hướng dẫn chạy và kiểm tra](SETUP-REACT-NATIVE.md). Các luồng tài khoản và eKYC hiện là demo, chưa kết nối backend.
